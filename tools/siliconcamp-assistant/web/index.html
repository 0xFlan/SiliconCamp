Introduction

SiliconCamp Assistant checks this Mac, the firmware images and the hypervisor's interrupt path before anything touches a disk.

It does not download Windows, partition the disk, or install anything. It reads this checkout and nothing else.

This Mac cannot install Windows yet.

The loader-to-kernel handoff is unsolved and there is no graphics driver. The remaining steps show what is ready and what is missing.

Before You Continue

A custom boot on the only Mac is hard to undo. These acknowledgements are stored in this browser only, and they do not enable installation.

A failed attempt can require a DFU restore.

A DFU restore erases the machine. None of these acknowledgements make the Windows boot path exist.

      Install Windows

      Windows cannot be installed on this Mac yet.

      The boot path does not exist, the graphics driver does not exist, and the internal SSD driver has never run on hardware.

      This control stays disabled until the boot path and drivers are real, not until the safety acknowledgements are checked.

      Why

      Boot path. No Windows kernel has run on this M4. The loader-to-kernel handoff is unsolved.

      Display. There is no WDDM driver for Apple AGX, so a booting kernel would have no desktop.

      Storage. AppleNANDStorageDxe is in the image but untested. USB storage is the only install path.

      Read-only. Nothing is downloaded or installed.
