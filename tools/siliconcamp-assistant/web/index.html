SiliconCamp Assistant

Introduction

This assistant prepares the disk side of running Windows on Apple silicon: it builds the Windows install media and works out how much of this Mac's storage can be given to Windows.

It writes only to an external USB disk or to a disk image you name. The internal SSD is not touched: Windows has never reached the kernel on this hardware.

Windows cannot boot on this Mac yet.

The loader-to-kernel handoff is unsolved and there is no graphics driver. Installer media built here is real and will be usable the day the handoff works.

Windows Installer

Choose a Windows 11 Arm64 ISO and a destination. The destination is erased, formatted as one FAT32 partition, written with the setup files and read back.

The Arm64 boot application is checked for its PE machine type, not just its name. The media also carries Autounattend.xml: it accepts the license, fixes the locale and bypasses the TPM, Secure Boot and RAM checks this Mac cannot satisfy. It never chooses or formats a disk.

Windows ISO

The ISO is mounted read-only, inspected and detached. Nothing is copied from it until you press Create Installer.

                  Windows cannot be installed on this Mac yet.
                  
      
                    The boot path does not exist, the graphics driver does not exist,
                    and the internal SSD driver has never run on hardware.
                  
      
                
      
              
      

              

              
      
                This control stays disabled until the boot path and drivers are
                real, not until the safety acknowledgements are checked.
              
      

              
      
                
      Why
      
                
      Boot path. No Windows kernel has run on this M4.
                The loader-to-kernel handoff is unsolved.
      
                
      Display. There is no WDDM driver for Apple AGX,
                so a booting kernel would have no desktop.
      
                
      Storage. AppleNANDStorageDxe is in the image but
                untested. USB storage is the only install path.
      
              
      
            
      
          
      

          
      
            
      Read-only. Nothing is downloaded or installed.
